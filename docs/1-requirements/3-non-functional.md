# ⚙️ Requisitos Não Funcionais

> Derivados das Histórias de Usuário HU-01 e HU-02.

Os requisitos não funcionais descrevem **como o sistema deve se comportar**.

| ID    | Categoria        | Descrição                                                                                       |
| ----- | ---------------- | ----------------------------------------------------------------------------------------------- |
| RNF01 | Desempenho       | O resultado deve ser exibido imediatamente após o toque no operador, sem atraso perceptível     |
| RNF02 | Usabilidade      | A interface deve ser operável com uma única mão; todos os controles visíveis sem rolagem        |
| RNF03 | Usabilidade      | O teclado numérico do sistema deve ser exibido automaticamente ao tocar nos campos de entrada   |
| RNF04 | Precisão         | O app deve suportar resultados com casas decimais (ex: 1 ÷ 5 = 0.2)                            |
| RNF05 | Compatibilidade  | O app deve funcionar em dispositivos Android com API Level 21 (Android 5.0) ou superior        |
| RNF06 | Distribuição     | O app é distribuído como arquivo `.apk` sem necessidade de publicação em loja oficial           |
| RNF07 | Manutenibilidade | O app deve ser editável pelo Kodular sem necessidade de IDE ou código nativo                    |
